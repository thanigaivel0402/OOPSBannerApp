# 🧩 OOPS Banner Application (UC1 → UC8)

## 📌 Project Overview
The **OOPS Banner Application** is a progressive **Java console-based project** designed to demonstrate **Object-Oriented Programming (OOP) principles**, **clean code practices**, and **incremental refactoring**.

The project starts with a simple console print (**UC1**) and evolves step by step into a **scalable, modular banner rendering engine** (**UC8**) using advanced Java concepts such as:

- Arrays & Loops  
- Methods & Classes  
- Collections Framework  
- HashMap  
- StringBuilder  
- Core OOPS design principles  

Each use case represents a meaningful refactoring step, following real-world development practices and **GitFlow-based version control**.

---

## 🎯 Objective
- Print the word **“OOPS”** in a banner (ASCII art) format  
- Improve the solution incrementally through multiple **Use Cases (UC1 → UC8)**  
- Demonstrate **refactoring**, **modularity**, **reusability**, and **clean architecture**  
- Apply real-world **OOPS concepts** in a structured and maintainable way
